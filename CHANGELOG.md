# Changelog

## 1.1.0 · 2026-10-17

- Native borderless desktop text with transparent background and click-through locking.
- Menu-bar preferences for sentence, font size and weight, color, opacity, wrapping and placement.
- Five named position presets, including a reference for the standard macOS lock-screen message.
- Full-screen anchors and one-physical-pixel position steppers on Retina displays.
- A custom multi-resolution app icon and a real desktop screenshot.
- Migration from the original settings format and 42 self checks.
- Documented Tim Cook / Stanford provenance for the demo sentence.
- An explicit macOS 14 deployment target, matching the APIs used by the application.

The included download is an Apple Silicon build. The source can be compiled
for Intel; that hardware and older macOS versions have not been runtime-tested.
